# AI Context

このディレクトリは、AIエージェントが実装時に参照するプロジェクト固有のコンテキストを配置するために使用します。

人間向けの設計資料、開発手順、運用ガイドは [`handbook/`](../handbook/) に配置してください。

> 日付入りのファイル（`*-YYYY-MM-DD.md`）は当時のスナップショットです。
> 2026-08 のフロントエンド統合（`apps/personal-app` への集約）より前のパス表記を含むため、
> 現行の構成は [`CLAUDE.md`](../CLAUDE.md) を参照してください。

## 配置基準

`docs/` に置くもの:

- AIエージェント向けの実装制約
- 自動化された作業で必要になる判断ルール
- AIがコード変更前に読み込むプロジェクト固有情報

`handbook/` に置くもの:

- 開発者向け設計ガイド
- セットアップ手順
- 運用手順
- 命名規約やコーディング規約
- 技術選定や設計判断の説明
